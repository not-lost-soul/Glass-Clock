# Changelog

## 3.0.0
* Rewrite around a transparent, cached glass bitmap: **no screen capture**, no per-frame drawing - fixes lag and flicker.
* New window placement: sits directly above wallpaper windows (Progman / WorkerW / Razer Axon / Wallpaper Engine / Lively); no more
  periodic "send to bottom". Optional *Embedded* mode, diagnostics dump, crash-proof logging.
* Day name as the big glass word, with date and time underneath (Rainmeter style).
* Bundled **Poppins** font (embedded in the exe), font import.
* New animated Liquid Glass settings window with live preview.
* Multi-file project, csproj, CI workflow, docs.

## 2.x
* Prototypes that sampled the screen for refraction (heavy, flickered, hid behind some wallpaper services).
